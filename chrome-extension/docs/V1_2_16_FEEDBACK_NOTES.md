# Chatpull Green v1.2.16 Feedback Notes

## 반영 사항

- 긴 프롬프팅 팁 문구가 한 줄에서 잘리지 않도록 최대 2줄 표시로 변경함.
- 입력 중 동일한 프롬프팅 팁이 반복적으로 새로 뜨는 느낌을 줄이기 위해 표시 시간, 반복 방지 시간, 소멸 후 대기 시간을 조정함.
- 프롬프팅 팁 탭의 재렌더링 애니메이션을 제거해 입력 중 깜빡임을 줄임.
- hover 환경 넛지 박스 크기를 줄이고 X 버튼을 제거함.
- 확장 프로그램 팝업에서 프롬프트 팁 모음 열기/접기 버튼과 카테고리별 팁 라이브러리를 제거함.
- 팝업은 확장 프로그램 on/off와 ChatGPT/Gemini 열기만 남기고, 프롬프팅 팁은 본 화면 플로팅 탭에 자동 노출되도록 유지함.
