# V1.2.15 Feedback Notes

## 반영 사항

1. 프롬프팅 팁 표시 방식 변경
   - 자동 프롬프팅 팁은 말풍선 팝업이 아니라 Tree Status Badge가 왼쪽으로 확장되는 inline tab으로 표시합니다.
   - 오른쪽 위 고정 배지 기준으로 너비가 왼쪽으로 늘어나도록 배치했습니다.

2. 환경 넛지와 프롬프팅 팁 역할 분리
   - hover 시에는 환경 넛지만 표시합니다.
   - 프롬프팅 팁은 입력 맥락 기반 자동 노출로 유지하되, 배지 확장형 UI로 바꿨습니다.

3. 팝업 닫기 UX 개선
   - 닫기 버튼뿐 아니라 배지 외부 클릭으로 열린 팝업과 inline tip을 닫을 수 있습니다.

4. 프롬프팅 팁 노출 시간 연장
   - 자동 프롬프팅 팁 노출 시간을 3.6초에서 7.2초로 늘렸습니다.

5. 확장 프로그램 팝업 개편
   - 현재 고정값, 위치 설정, 오늘 통계, 최근 로그 영역을 제거했습니다.
   - 기존 prompt-tips.js의 조언을 카테고리별로 탐색하는 창을 추가했습니다.
