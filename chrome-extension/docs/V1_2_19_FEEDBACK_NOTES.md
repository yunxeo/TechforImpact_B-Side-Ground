# Chatpull Green v1.2.19 피드백 반영

## 변경 사항

- 첫 사용 가이드가 자동 소멸되지 않도록 변경했습니다.
  - 키보드 입력 또는 마우스 클릭이 발생하면 닫히고, 이후에는 다시 자동 표시되지 않습니다.
- 확장 프로그램 팝업에 `처음 사용 팁` 카드를 추가했습니다.
  - `사용 팁 열기 / 접기` 버튼으로 내용을 펼치고 접을 수 있습니다.
- 프롬프팅 팁 탭에 접힘 애니메이션을 추가했습니다.
  - 펼침: 1.5초
  - 접힘: 1.5초
- 챗풀 로고/상태 배지는 원래 위치에 고정하고, 팁 탭만 왼쪽으로 펼쳐지도록 유지했습니다.
- 펼쳐진 팁 바의 배경을 완전한 흰색으로 바꾸고, 로고와 팁 바가 하나의 덩어리처럼 보이도록 그림자 세기를 통일했습니다.
- 환경 넛지 박스의 최대 폭과 padding을 한 번 더 줄였습니다.
