# Chatpull Green v1.2.14 Feedback Notes

2026-05-18 피드백 반영 버전입니다.

## 반영 사항

1. 사용자 이득과 환경 메시지 분리
   - 프롬프팅 팁: 입력 맥락에 따라 자동 노출
   - 환경 넛지: 나무 배지 hover 시 노출

2. 위치 정책 정리
   - 기본 위치: 채팅창 오른쪽 위
   - 위치 preset 선택 UI 제거
   - 드래그 이동은 필요 시 popup에서 켜는 방식 유지

3. 시각 조정
   - 배지 및 문구 스케일 80% 적용
   - 그림자 blur와 opacity 완화
   - 배지의 물 사용 은유 문구 제거

4. 팝업 UX
   - 자동 소멸 유지
   - 작은 X 버튼으로 수동 닫기 가능
   - 레벨 진입 팝업 체류 시간 증가
   - 프롬프팅 팁 팝업 체류 시간 단축

5. 온보딩
