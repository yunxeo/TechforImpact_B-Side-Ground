# Chatpull Green v1.2.17 Feedback Notes

## 반영 사항

- 프롬프팅 팁 플로팅 탭의 입력 중 재렌더링을 줄였습니다.
  - 팁이 떠 있는 동안에는 상태 텍스트만 패치합니다.
  - 팁 DOM을 매 입력마다 다시 만들지 않아, 문장이 계속 새로 뜨는 느낌을 줄였습니다.
  - 첫 노출 애니메이션은 유지했습니다.
- 프롬프팅 팁 글자 크기를 환경 넛지 수준에 맞춰 키웠습니다.
- 환경 넛지 박스의 폭, padding, radius, shadow를 추가로 줄였습니다.
- 환경 넛지 박스에는 닫기 버튼을 두지 않는 상태를 유지했습니다.
- 확장 프로그램 팝업에 프롬프트 팁 모음을 복구했습니다.
  - 열기 / 접기 버튼이 실제로 작동합니다.
  - 카테고리별 필터와 목록이 표시됩니다.
- manifest version을 0.3.17로 올렸습니다.
