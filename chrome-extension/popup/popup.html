Usage Guide

처음 사용 팁

ChatGPT·Gemini 입력창 위에 뜨는 챗풀 배지와 팁을 쓰는 방법입니다.

1. 프롬프팅 팁

입력 상황에 맞는 조언이 챗풀 배지 왼쪽으로 펼쳐집니다.

2. 환경 넛지

나무 배지에 마우스를 올렸을 때만 작은 환경 넛지가 표시됩니다.

3. 닫기 방식

배지 바깥 영역을 클릭하면 열린 팁과 넛지가 닫힙니다.
