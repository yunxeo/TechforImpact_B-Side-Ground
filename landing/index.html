그루 설치 방법

⬇ zip 파일 다운로드
  1. 1위 버튼으로 zip 파일을 다운로드한 후 압축을 풀어주세요.
  2. 2Chrome 주소창에 chrome://extensions 을 입력하고 이동합니다.
  3. 3우측 상단의 개발자 모드 스위치를 켜주세요.
  4. 4압축 해제된 확장 프로그램 로드 버튼을 클릭합니다.
  5. 5압축을 푼 chrome-extension 폴더를 선택하면 설치 완료입니다!

설치 후 ChatGPT·Claude·Gemini 접속 시 자동으로 그루가 활성화됩니다.
